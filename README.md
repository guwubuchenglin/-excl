# 检验记录表

一个基于 HTML/CSS/JS 的检验记录管理系统，运行在浏览器端，数据存储在 localStorage 中。

## 功能特性

- 🧩 **多系列管理** — 顶部系列切换器支持新建/重命名/删除系列（如"施耐德""西门子"），每个系列的物料库和检验记录完全独立存储、互不干扰，切换系列即切换整套数据
- 📝 **检验数据录入** — 录入客户、生产订单、物料编码、图号、数量、不合格数量，不合格原因支持预设选项或自定义填写
- 📅 **自由切换日期** — 页头日期选择器可切换到任意日期，录入、编辑、查看、导出均针对选中日期操作，历史数据按日期独立存储
- 📦 **物料库管理** — 维护物料编码、图号、客户的关联关系，支持按物料编码或图号模糊搜索、批量导入/导出 Excel，同编码+图号自动合并
- 🔍 **智能匹配下拉** — 输入客户、物料编码、图号时均触发模糊搜索下拉提示，点击一键回填关联字段
- 📜 **历史记录查询** — 日期自定义范围 + 快捷预设（今天/本周/本月/全部），按客户、物料编码筛选，分页浏览
- 📊 **汇总报表** — 四格概览 + 按客户/物料/不合格原因三个维度排行，支持导出多 Sheet 汇总 Excel
- 🗂️ **可折叠面板** — 物料库管理、历史记录查询、汇总报表、今日记录列表等区块可一键展开/收起，界面更清爽
- 💾 **右上角全量备份** — 页头右上角「💾 备份」按钮，下拉菜单一键导出/导入全部系列的所有数据（JSON 格式），换手机时整体迁移
- 💾 **按系列备份恢复** — 「数据备份/恢复」卡片支持按当前系列导出/恢复数据；每月 1~3 日导出 Excel 时自动附带全量 JSON 备份
- 📥 **Excel 导出** — 当日记录导出（含表头、合计行、检验日期、检验员），汇总报表导出，物料库导出

## 多系列说明

每个系列拥有独立的数据存储空间：

- 检验记录存储于 `recordsByDate_系列名`
- 物料库存储于 `materialDB_系列名`
- 首次打开时，旧版本的单系列数据会自动迁移到「施耐德」系列

顶部页头可切换系列、新建系列、重命名系列、删除系列。删除系列会同时清除该系列的全部数据，操作前有二次确认。

## 换手机 / 迁移数据

页头右上角点「💾 备份」：

1. **导出全部系列数据** — 生成一个 JSON 文件，包含所有系列的检验记录和物料库
2. 在新手机/浏览器打开本页面，点**导入全部系列数据**，选择该 JSON 文件即可完整恢复

导入会覆盖当前设备上的全部系列数据，操作前有确认提示。

## 快速开始

直接用浏览器打开 `index.html` 即可使用。所有数据存储在浏览器 localStorage 中，无需服务器。

## 技术栈

- 纯 HTML/CSS/JavaScript，无框架依赖
- [SheetJS (xlsx)](https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js) — Excel 读写，通过 jsdelivr CDN 加载
- localStorage — 数据持久化

## 浏览器兼容

支持所有现代浏览器（Chrome、Firefox、Safari、Edge）。
