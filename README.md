# 检验记录表

一个基于 HTML/CSS/JS 的检验记录管理系统，运行在浏览器端，数据存储在 localStorage 中。

## 功能特性

- 🧩 **多系列管理** — 顶部系列切换器支持新建/重命名/删除系列（如"施耐德""西门子"），每个系列的物料库和检验记录完全独立存储、互不干扰，切换系列即切换整套数据
- 📝 **检验数据录入** — 录入客户、生产订单、物料编码、图号、数量、不合格数量；有不合格时先选不良分类（外观/尺寸/材质/性能/装配/包装/其他），再填写具体不合格原因（工厂终检式录入）
- 🚚 **发货前检查（另一项目）** — 「录入检验数据」卡片顶部用页签切换「🔍 检验数据 / 🚚 发货前检查」，发货前检查**只需图号 + 数量**两个字段（图号可从物料库图号中选，也可直接手输新图号）。输入图号时会**按图号到物料库匹配**，实时显示该图号对应的客户与物料编码（一个图号对应多个客户时全部列出并提示）。**匹配不到时保存会自动建档**：往物料库加一条「只有图号、没有物料编码」的物料（客户留空，之后可在物料库补填），下次输入就有候选、不用再手输；只在图号完全不存在时新增，所以不会把已有物料的多个条目搞乱。记录本身只保存图号 + 数量，匹配结果在显示时实时解析，物料库后续补充/补填客户后，历史记录会自动显示出客户。同样按日期存储、共用页头日期，卡片内显示当天记录列表与数量合计，可编辑/删除。数据独立存放（`shipRecordsByDate_系列名`），与检验记录互不干扰
- 🤖 **新产品自动入库** — 保存检验记录时，若「物料编码+图号」在物料库中不存在，会自动新增该产品（客户一并带入），无需再手动维护物料库；已存在的产品不会被重复添加，也不会覆盖物料库里已有的客户
- 📅 **自由切换日期** — 页头日期选择器可切换到任意日期，录入、编辑、查看、导出均针对选中日期操作，历史数据按日期独立存储
- 📦 **物料库管理** — 维护物料编码、图号、客户的关联关系，支持按物料编码或图号模糊搜索、批量导入/导出 Excel，同编码+图号自动合并；客户字段支持下拉选择已有客户，或直接输入新增客户（保存后自动进入客户列表）。物料编码可以为空（发货前检查自动建档的条目就没有编码，列表里显示「（未填编码）」，之后可编辑补填）
- 📤 **物料库导入不串列** — 导入 Excel 后先弹「确认列对应」窗口：自动认表头（物料编码/料号/图号/图纸号/客户/Item No/Drawing No 等中英文别名），表头认不出就按**数据内容**判断（公司名→客户、长编码→图号、短编码→物料编码）；如果**表头写的顺序和数据的实际顺序不一致**（例如表头写「物料编码,图号,客户」但数据其实是「客户,物料编码,图号」），会自动以数据内容为准并明确提示。窗口里给出「导入后的样子」预览，三个下拉可随时手动改列，确认没问题再导入。检测到现有物料库里残留历史错位数据时也会提示清理
- 🗑️ **物料批量删除** — 「已存物料」下方点「☑️ 批量删除」进入批量模式：每行出现复选框（点整行也可勾选），支持全选本页、翻页后跨页累计勾选，一键删除选中的多条物料（删除前提示条数）；另有一键清空物料库（二次确认，可从备份恢复）
- 🔍 **智能匹配下拉** — 输入客户、物料编码、图号时均触发模糊搜索下拉提示，点击一键回填关联字段；物料库与录入区的客户下拉均自动去重汇总全部已有客户
- 🧑💼 **客户管理** — 客户名由物料库与检验记录的客户字段自动汇总（不是独立数据表）。「🧑💼 客户管理」卡片列出全部客户及各自的物料/记录条数，支持按名称筛选、**改名**、**删除**：删除时可选「清空客户字段」或「把名下数据转给另一个客户」，并同步处理全部系列的物料与检验记录（执行前显示影响条数）；物料库表单新增「📋 从已有客户选择」按钮
- 📜 **历史记录查询** — 日期自定义范围 + 快捷预设（今天/本周/本月/全部），按客户、物料编码筛选，分页浏览
- 📊 **汇总报表** — 四格概览 + 按客户/物料/不合格原因三个维度排行（页面标签切换），导出为单个工作表：顶部概览（日期范围、筛选条件、汇总指标）+ 物料明细表（客户、物料/图号、检验数量、不合格数量、不合格率、不良类型、不合格原因）
- 🗂️ **可折叠面板** — 物料库管理、历史记录查询、汇总报表、今日记录列表等区块可一键展开/收起，界面更清爽
- 💾 **右上角全量备份** — 页头右上角「💾 备份」按钮，下拉菜单含云同步（上传/拉取/历史快照/设置）和本地文件备份（导出/导入全部系列 JSON），换手机时整体迁移
- 🕘 **自动云端备份** — 打开页面自动把最新数据上传到云端；Worker 每天凌晨自动存一份带日期的历史快照，保留 30 天，误操作也能找回
- 💾 **按系列备份恢复** — 「数据备份/恢复」卡片支持按当前系列导出/恢复数据；每月 1~3 日导出 Excel 时自动附带全量 JSON 备份
- 📥 **Excel 导出** — 当日记录导出（含表头、合计行、检验日期、检验员；当天有发货前检查时额外多一个「发货前检查」工作表，含图号/数量/合计），汇总报表导出，物料库导出

## 云同步（Cloudflare KV）

数据不仅可以存在浏览器本地，还可以免费同步到 Cloudflare KV，换设备 / 多设备之间共享数据。

### 首次部署（一次即可）

1. **注册 Cloudflare**（免费）→ Dashboard → Workers & Pages → KV，创建一个 KV 命名空间
2. **创建 Worker** → 把仓库里的 [`worker.js`](./worker.js) 全部内容粘贴进去 → 部署
3. 在 Worker 的 **Settings → Variables** 中添加：
   - `WRITE_PASSWORD`：你自己设的写密码（网页上传数据时要用）
   - **KV Namespace Bindings**：变量名填 `KV`，选择你建好的 KV 命名空间
4. **开启定时快照**：Settings → Triggers → Cron Triggers，添加 `0 2 * * *`（每天凌晨2点自动快照）
5. 记下 Worker 地址（形如 `https://xxx.workers.dev`）

### 网页端配置

页头右上角「💾 备份」→ **⚙️ 云同步设置**，填入 Worker 地址和写密码。地址默认预填，密码填一次后自动记住，之后打开页面会自动静默上传。

### 使用

- **⬆️ 上传到云端**：手动把当前全部系列的数据推送到 KV
- **⬇️ 从云端拉取**：拉取云端数据并覆盖本地（有确认提示）
- **📸 立即创建快照**：手动把当前数据存为当天快照，不依赖定时触发
- **🕘 云端历史快照**：列出云端自动备份的日期，选择某天快照恢复本地（覆盖前有确认）。若提示获取失败，说明云端 Worker 是旧版，请按上文重新部署最新 [`worker.js`](./worker.js)
- **自动备份**：每次打开页面静默上传最新数据；Worker 每天凌晨自动把当天数据存为 `backup_日期` 快照，保留 30 天（需在 Triggers 配置 `0 2 * * *` 定时触发）

云端存储空间免费额度 1GB，个人使用绰绰有余。KV 是"最终一致性"，写入后全球同步约需 1 分钟，日常单机使用无影响。

## 多系列说明

每个系列拥有独立的数据存储空间：

- 检验记录存储于 `recordsByDate_系列名`
- 物料库存储于 `materialDB_系列名`
- 发货前检查存储于 `shipRecordsByDate_系列名`
- 首次打开时，旧版本的单系列数据会自动迁移到「施耐德」系列

顶部页头可切换系列、新建系列、重命名系列、删除系列。删除系列会同时清除该系列的全部数据，操作前有二次确认。

## 换手机 / 迁移数据

页头右上角点「💾 备份」：

1. **导出全部系列数据** — 生成一个 JSON 文件，包含所有系列的检验记录、物料库和发货前检查记录
2. 在新手机/浏览器打开本页面，点**导入全部系列数据**，选择该 JSON 文件即可完整恢复

导入会覆盖当前设备上的全部系列数据，操作前有确认提示。

## 快速开始

直接用浏览器打开 `index.html` 即可使用。所有数据存储在浏览器 localStorage 中，无需服务器。

## 技术栈

- 纯 HTML/CSS/JavaScript，无框架依赖
- [SheetJS (xlsx)](https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js) — Excel 读写，通过 jsdelivr CDN 加载
- localStorage — 本地数据持久化
- [Cloudflare Workers + KV](https://developers.cloudflare.com/kv/) — 免费云同步（可选）

## 浏览器兼容

支持所有现代浏览器（Chrome、Firefox、Safari、Edge）。
